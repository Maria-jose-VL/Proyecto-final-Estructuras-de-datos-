# Proyecto Final - Estructuras de Datos

## Descripción
Proyecto final de la asignatura Estructuras de Datos, correspondiente al programa de Ingeniería de Sistemas y Computación de la Universidad del Quindío.

## Objetivo
Desarrollar una solución que permita aplicar los conceptos y estructuras de datos estudiados durante el curso en un contexto específico. 

## Tecnologías
- Lenguaje de programación: Java, java FX (interfaz gráfica)
- Git y GitHub para el control de versiones.
